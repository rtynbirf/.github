# АТЛАС-МЕХАНИЗМ · Global Practice Atlas v1.4

Рабочий механизм верификации практик: данные + конечный автомат (РЕЛОМАТ) + CI.
Состояние на 2026-11-20: **1154 строки паспортов (1150 живых), 4 поглощения с сохранением строк, автомат 43/43, эмерджентные линии 11/11, unittest OK.**

## Где что живёт

| Репозиторий | Роль | Вход |
|---|---|---|
| `relomat` | Канон как конечный автомат: строки-отношения → вердикты (SAME/IS-A/TOOL-OF/COMPLEMENTARY/METHOD-OF/INSTANCE/RELATED/NEW) | `python3 run_all.py` |
| `global-practice-atlas` | Каталог практик: паспорта, двойное кодирование, реестр вердиктов, поставки (XLSX/CSV/JSON) | CI: `qa_atlas.py` (12 проверок данных + результаты автомата) |

## Запуск механизма локально

```bash
git clone https://github.com/rtynbirf/relomat && cd relomat
python3 run_all.py          # пары → автомат → эмерджентные → unittest; ненулевой код при расхождении
```

CI обоих репозиториев исполняет то же самое на каждый push: relomat — unittest + автомат + эмерджентные; atlas — самостоятельный QA данных (счётчики, M-агрегат, классы, прямой путь R1, сверка AI Index, результаты РЕЛОМАТА 43/43 и 11/11).
