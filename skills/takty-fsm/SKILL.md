# Такт FSM

Скрипт: `domovoy-ritual/house_fsm.py` (клон `rtynbirf/domovoy-ritual`). Машина состояний
отклоняет неверный порядок — не обходи, перестраивай такт.

1. **ВХОД** `enter --mandate "..."` — мандат: что вводится и на каком основании.
2. **ДЕЛО** `work --task "..."` — сама работа.
3. **СВЕРКА** `verify --facts "..."` — заявления против фактов (git, постчек, чистые клоны).
4. **ПЛОМБА** `seal`, затем **УБОРКА** `clean`, затем `status` → S0 ПОКОЙ.

Гигиена:
- Секрет — только tmp с правом 600; в файлы и .git/config не записывать; стереть к ПОКОЙ; grep-след = 0.
- tmp такта должен быть пуст к покою — иначе ПОКОЙ недостижим.
- Среда грязная — FSM уберёт сам (G1) и отметит.

Проверено: волны 18–19 замкнулись S0; попытка verify из ВХОД была отвергнута машиной —
правильная цепочка только через ДЕЛО→СВЕРКА.
