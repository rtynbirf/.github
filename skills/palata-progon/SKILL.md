# Палата

Скрипт: `singulyar:rumu → progonnaya_palata/palata.py` (не входит в pytest-коллекцию стенда).

```bash
python3 palata.py --journal <журнал> --tree <корень> [--tmp <tmp>] [--self]
# волна-20, районные сценарии:
python3 palata.py --district <клон index> <клон .github>
```

Сценарии: Х-061 запись такта · Х-062 ноль следов токена · Х-063 манифест П2 · Х-064 tmp пуст ·
Х-065 память дома свежее акта · Х-066 навыки валидны + паспорт района · Х-067 карточки деятелей валидны.

Статусы по ст. 68: **ВЫПОЛНЕНО** — по факту; **ЗАЯВЛЕНО** — заявлено, не исполнено (считать
невыполненным); **НЕ ПРОВЕРЕНО** — неисполнимо в этой среде. Приговор выносит Хозяин.
LLM-судья не подменяет детерминированный там, где хватает assert/grep/sha256.
Проверено: волна-19 дымопрогон — самопроба дала ЗАЯВЛЕНО до уборки и ВЫПОЛНЕНО после.
