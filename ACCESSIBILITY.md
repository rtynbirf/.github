# Доступность (Accessibility)

Этот аккаунт стремится делать свои материалы доступными.

**Цели:** семантическая разметка в веб-интерфейсах; контраст текста по WCAG 2.1 AA;
навигация с клавиатуры; текстовые альтернативы для ключевых визуальных материалов.

**Сообщить о барьере:** откройте issue с ярлыком `accessibility` — барьер будет
рассмотрен и включён в план работ.
