## 1 · Разведка мировых практик (что взято на карандаш)

Три агента, параллельно; источники открыты и прочитаны, не по памяти:

- **Токены/аутентификация**: официальный канон GitHub — иерархия
  GITHUB_TOKEN → GitHub App → fine-grained PAT → classic PAT; expiry 30–90 дней;
  «лучшая ротация — та, что не нужна» (GitGuardian: 64% живых секретов 2022
  живы в 2026); секреты — в менеджерах, не в файлах; push protection везде.
- **Хардненинг Actions**: пин сторонних actions на полный SHA (ratchet /
  pin-github-action / StepSecurity secure-repo); deny-all permissions сверху +
  выдача по задаче; timeout-minutes на каждый job (дефолт платформы 360 мин!);
  concurrency; OIDC вместо долгоживущих секретов; Scorecard как непрерывный аудит.
- **Репо-самоаудит**: OpenSSF Scorecard + OSPS Baseline (машиночитаемый каталог
  соответствия); Allstar и scorecard-monitor — паттерн «сверка состояния с
  политикой → issue при дивергенции, авто-закрытие при приведении в
  соответствие»; durable-owner у GitHub — CronJob-реконсиляция с расхождениями.

Эмерджентная брешь канвы: во всей мировой практике **нет органа, который
проверяет живость самих аудиторов**. Scorecard мерит репо, Allstar мерит
политики — но если планировщик аудита замолчал, это заметит только человек.
Закрыто в §4.

## 3 · Эмерджентный синтез (только своё)

- **Принцип трёхслойного доказательства**: орган считается живым, только если
  (а) прогон зелёный, (б) факт запечатан в репо, (в) след свежий. Одного
  зелёного прогона недостаточно — дыра, через которую дом молчал 8 дней.
- **Дозор дозора**: минимальный орган (только репорт; лечение не выполняет —
  закон ревизора), который сверяет (1) печать дома (набор archived-репо) с
  baseline — GitOps-реконсиляция печати; (2) живость органов-дозоров (canon
  workflow state=active); (3) свежесть снимков; (4) исторические следы реестра
  #10. Дивергенция → ALARM-issue с дедупом по WARDEN-FP; приведение в
  соответствие → авто-закрытие алармов (паттерн Allstar); зелёный — молчит.
- **Seal-step**: коммит факта через API с ВИДИМЫМ отказом (exit 1) — против
  молчаливого `False` в логах. Правило: «доказательство, не запечатанное в репо,
  не существует».
- **Живой fallback вместо мёртвого секрета**: флот публичен целиком → осмотр
  обязан работать при любом состоянии PAT: fallback на `github.token`
  (живёт ровно один прогон — по мировой практике лучше любого долгоживущего
  секрета) + вердикт по публичному срезу.
- **Печать как first-class состояние**: архивация дома — не хаос, а фиксируется
  в baseline; вскрытие печати без хозяина = ALARM (трипваер наоборот).
