## 2. Задание раунда («БЕРЕЖЁННОГО БОГ БЕРЕЖЁТ»)

- **метаданные**: issues + комментарии, PR + ревью + комментарии, releases, tags, milestones, labels, branches — по каждому телу в meta/*.json;
- **профиль**: /user, ключи, организации, подписки;
