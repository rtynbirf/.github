# AGENTS.md — .github

Мета-репо дома: дефолты профиля (templates, health files), которые наследует витрина.

Что делать агенту:
- здесь живут общие шаблоны (issue/PR, CODEOWNERS, security) — менять аккуратно, они тиражируются;
- ничего runtime-ового не хранить: это не клетка, а рама дома.

## Правила дома (общие для всех клеток)

1. **Печать до разрушения** — любое опасное действие (переписать историю, удалить ветку, урезать тело) сначала даёт печать: git bundle / SHA256-манифест в `polimat-hub/vault/`.
2. **Числа никогда руками** — счётчики, даты, размеры только из живого API; выдуманная цифра = косяк.
3. **Связь пинами, не импортами** — клетки ссылаются на тело пином (body_pin), не копипастой.
4. **Честный красный лучше зелёной лжи** — не глушить проверки; ошибка чинится, не прячется.
5. **Мембрана из трёх слоёв** — README.md (человек), AGENTS.md (агент, этот файл), llms.txt (машина).
6. **Коммиты от rtynbirf-labs** — правки агентов помечаются в сообщении коммита; никаких секретов в коде.

## Гигиена агента (Волна ×10, 2026-11-10)

Канон: repo-doctrine → `21-гигиена-уведомлений-и-красного-CI-2026-11-09.md`. Вход по закону: `github-runbook#10` (РЕЕСТР НЕДОДЕЛАННОГО · закон §5) + РЕЕСТР-КОСЯКОВ-ИИ + АНАТОМИЯ-КОСЯКОВ-ИИ (polimat-hub) — читать ДО первого действия.

1. Красный CI от твоего коммита — твой долг: живой зелёный прогон до конца сессии (rerun/диспатч/лат). Честный красный (внешний блок) — пломбой в github-runbook#10, не прятать.
2. Новые файлы — в манифесты тем же коммитом: SPDX/REUSE.toml, MANIFEST/portability.json, геном cell-swarm/swarm.json (пин следит за телом).
3. Не плодить уведомления: свой прогон доведи до зелёного; входящие треды разобрать и пометить прочитанными; UNREAD=0 — норма.
4. Пуш-гигиена: `pull --rebase` перед пушем; force-push запрещён; чужие волны и авто-коммиты (§3 реестра) не трогать; дубль снят честно = нет дубля.
