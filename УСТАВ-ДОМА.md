# 🏠 УСТАВ ДОМА «Полимат-Универсум» · аккаунт-уровень

*Мандат Хозяина 2026-11-11. Принцип: **карта = территория**. Теория конечных автоматов:
у каждой работы есть терминальное состояние — **ЧИСТ**. Никаких висяков: ни issue, ни
красного прогона, ни непрочитанной нотификации. Человек не делает того, что может
сделать агент или машина.*

---

## 1. РИТУАЛ: конечный автомат работы

```
[РАБОТАЕТ] → [СДЕЛАЛ] → [УБРАЛ] → [ЧИСТ]
     ↑            ↓          ↓
     └── возврат ─┘   иначе: сигнал роя
```

| Такт | Суть | Доказательство |
|---|---|---|
| **ПОРАБОТАЛ** | работа зафиксирована в git (коммиты, без «в уме») | SHA в истории |
| **СДЕЛАЛ** | гейты зелёные | последний прогон воркфлоу = success/skipped |
| **УБРАЛ** | следы стёрты: ghost-прогоны удалены, манифесты пересобраны, нотификации прочитаны, учёт недоделок перенесён | `house-sweep` вердикт + CHRONICLE |
| **ЧИСТ** | инварианты дома выполняются | сводка инвариантов — все ✅ |

Сессия агента не завершена, пока автомат не дошёл до **ЧИСТ**. Это не пожелание — это
закон: любой воркфлоу, репо, issue обязаны прийти к терминальному состоянию.

## 2. Инварианты дома (машинно проверяемые)

- **I-1 · Очередь = 0.** Открытых issues и PR по аккаунту — 0. Закрытие — только с
  факт-комментарием: `completed` → SHA/прогон; `not_planned` → точный перенос учёта
  в TODO.md / реестр волны. Ничего не теряется — терминальные состояния честные.
- **I-2 · Последний прогон зелёный.** Для каждого воркфлоу каждого репо последний
  прогон ∈ {success, skipped}. Исторические падения — не грех; красный *хвост* — грех.
- **I-3 · Inbox-zero.** Непрочитанных нотификаций — 0 (PUT /notifications после уборки).
- **I-4 · Карта = территория.** Манифесты/фасады/каталоги (MANIFEST_SHA256.txt,
  llms-account.txt, крон-зрение) сходятся с живым API. Карта отстала → пересобрать,
  а не подогнать.
- **I-5 · Секреты — только в Actions secrets.** Ничего живого в коде, истории, чатах.
  Токен светился в чате → немедленная ротация.
- **I-6 · Ghost-нуль.** Прогонов с `conclusion=failure` и 0 джобов не существует:
  это мусор битых регистраций, подлежит удалению, а не «жизнь с ним».

## 3. Обязательный алгоритм (исполняется агентом или машиной)

1. Начал работу → работа в git (ветка/коммит), никакой работы «вне репозитория».
2. Доделал → прогон гейта (push или `workflow_dispatch`); красный = не СДЕЛАЛ.
3. Убрал за собой → `house-sweep` (или те же шаги вручную): ghost-нуль, dependabot-старьё,
   нотификации-0, манифесты пересобраны, учёт перенесён.
4. Отчитался фактом → CHRONICLE.md дополнен датированной строкой.
5. Терминал → **ЧИСТ**; иначе автомат не закрыт, работа продолжается.

## 5. Запреты (никогда)

- Не оставлять красный **последний** прогон: починить код, затем dispatch-доказательство,
  затем убрать хвост.
- Не заводить issue без необходимости; очередь = 0 — норма, а не подвиг.
- Не править пломбы/манифесты руками — только генерацией (`make manifest`, робот-синхронизатор).
- Не писать секреты в код, историю, чаты; засветил — ротируй.
- Не удалять чужие факт-комментарии закрытий — летопись append-only.
