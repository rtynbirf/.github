# АТЛАС-МЕХАНИЗМ · Global Practice Atlas v1.5

Рабочий механизм верификации практик: данные + конечный автомат (РЕЛОМАТ) + CI + скан + релизы.
Состояние на 2026-11-20: **1154 строки паспортов (1145 живых), 9 поглощений с сохранением строк, автомат 43/43, эмерджентные линии 11/11, QA 15 проверок, unittest OK.**

## Где что живёт

| Репозиторий | Роль | Вход |
|---|---|---|
| `relomat` | Канон как конечный автомат: строки-отношения → вердикты (SAME/IS-A/TOOL-OF/COMPLEMENTARY/METHOD-OF/INSTANCE/RELATED/NEW) | `python3 run_all.py` |
| `global-practice-atlas` | Каталог практик: паспорта, двойное кодирование, реестр вердиктов, поставки (XLSX/CSV/JSON), релиз [v1.5](https://github.com/rtynbirf/global-practice-atlas/releases/tag/v1.5) с артефактами | CI: `qa_atlas.py` (15 проверок) |
| `rtynbirf` (профиль) | Виджет «КАРТА = ТЕРРИТОРИИ»: SVG перерисовывается на автомате из данных атласа | workflow `atlas-widget` |

## Запуск механизма локально

```bash
git clone https://github.com/rtynbirf/relomat && cd relomat
python3 run_all.py          # пары → автомат → эмерджентные → unittest; ненулевой код при расхождении
```

## Что добавил v1.5 (механика, не декларация)

- **Глобальный парный скан**: полный перебор 660,675 пар живых позиций; прегейнджер по токенам (Жаккар > 0.5) → 30 кандидатов → РЕЛОМАТ: 5 SAME + 4 IS-A + 21 RELATED. Найдены 5 полных дублей, которых двойное кодирование не видело: 877→597 Personal Data Stores, 971→499 Resilience Engineering, 326→269 Systems Thinking, 962→231 Federated Governance, 714→111 Bayesian Experimental Design. Канон исполнен: цель — первичная запись аудита, источник поглощён с сохранением строки.
- **CI атласа исполняет автомат независимо**: checkout relomat, перепрогон 43/43 + 11/11 по данным атласа; qa_atlas сверяет живой перепрогон, а не записанный отчёт.
- **Схема**: поля `source_url` и `verified_on` — сверки следующего года машинные.
- **Тренд-обход по расписанию**: cron ежемесячно; сиды → R5-фильтр → дифф `data/trend_sweep_report.json`; кандидаты — только сигнал, автослияние запрещено.
- **Поставки адресуемы**: тег v1.5 + Release с XLSX/CSV/JSON.

## Свита и король — чего не видно изнутри песочницы

1. **Пины профиля пусты** (GraphQL `pinnedItems` → `[]`). Канон знает: «пины API не выставляет» — раскладка 6 клеток остаётся ручной работой хозяина в веб-интерфейсе.
2. **`global-practice-atlas` и `relomat` вне генома 20 клеток** (README профиля, канон 0.2.14) — свита канона не знает о новой клетке-карте. Включение в геном — решение хозяина, не автопилота.
3. **PDF AI Index 2026 недоступен из песочницы** (404 на прямой URL) — два числа (78% за 2024, +280% вакансий) остаются честно помеченными сниппет-уровнем.
