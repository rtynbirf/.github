# АТЛАС-МЕХАНИЗМ · Global Practice Atlas v1.6

Рабочий механизм верификации практик: данные + конечный автомат (РЕЛОМАТ) + CI + скан + релизы + сверка полным текстом PDF.
Состояние на 2026-11-20: **1154 строки паспортов (1145 живых), 9 поглощений с сохранением строк, автомат 43/43, эмерджентные линии 11/11, QA 16 проверок, unittest OK, open_fields по AI Index = 0.**

## Где что живёт

| Репозиторий | Роль | Вход |
|---|---|---|
| `relomat` | Канон как конечный автомат: строки-отношения → вердикты (SAME/IS-A/TOOL-OF/COMPLEMENTARY/METHOD-OF/INSTANCE/RELATED/NEW) | `python3 run_all.py` |
| `global-practice-atlas` | Каталог практик: паспорта, двойное кодирование, реестр вердиктов, поставки (XLSX/CSV/JSON), релиз [v1.6](https://github.com/rtynbirf/global-practice-atlas/releases/tag/v1.6) с артефактами | CI: `qa_atlas.py` (16 проверок) |
| `rtynbirf` (профиль) | Виджет «КАРТА = ТЕРРИТОРИИ»: SVG перерисовывается на автомате из данных атласа | workflow `atlas-widget` |

## Запуск механизма локально

```bash
git clone https://github.com/rtynbirf/relomat && cd relomat
python3 run_all.py          # пары → автомат → эмерджентные → unittest; ненулевой код при расхождении
```
