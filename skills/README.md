# НАВЫКИ ДОМА · индекс (Ф-Н · волна-20)

Мировая опора: Agent Skills — открытый стандарт (SKILL.md: каталог с YAML-frontmatter
`name` + `description`; подарен Anthropic в Agentic AI Foundation 22.10.2026).
Навык = процедура, которую ЛЮБОЙ агент дома загружает перед делом — кодификация
директивы «напиши другим агентам, чтоб выполняли эту процедуру».

## Правила

1. Формат — по стандарту: frontmatter `name` (≤64 знаков), `description` (что и когда, ≤1024).
2. Навык ссылается на канон и репо, не дублирует их: сверки — в ПРОТОКОЛ-СВЕРКИ-СПЕЦ-КОД, пломбы — в release-vault/PLAMBA.md.
3. Смена навыка = новый коммит + запись в ЛЕТОПИСЬ; навсегда с SHA256 в манифесте волны.
4. Пломба навыков: SHA256SUMS_волны-20 в download стража; сверка П2 — в палате (Х-066).
