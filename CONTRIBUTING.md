# Contributing

Этот репозиторий — носитель дефолтных community health files аккаунта. Изменения:

1. Сначала issue с обоснованием.
2. PR маленькие и точечные, один файл/тема за раз.
3. CI зелёный до ревью. Секреты не коммитятся.

Файлы отсюда наследуются всеми репо аккаунта — держите их нейтральными.
