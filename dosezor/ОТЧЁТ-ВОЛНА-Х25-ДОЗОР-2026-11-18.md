## 1 · Разведка мировых практик (что взято на карандаш)

Три агента, параллельно; источники открыты и прочитаны, не по памяти:

- **Токены/аутентификация**: официальный канон GitHub — иерархия
  GITHUB_TOKEN → GitHub App → fine-grained PAT → classic PAT; expiry 30–90 дней;
  «лучшая ротация — та, что не нужна» (GitGuardian: 64% живых секретов 2022
  живы в 2026); секреты — в менеджерах, не в файлах; push protection везде.
- **Хардненинг Actions**: пин сторонних actions на полный SHA (инструменты
  ratchet / pin-github-action / StepSecurity secure-repo); deny-all permissions
  сверху + выдача по задаче; timeout-minutes на каждый job (дефолт 360 мин!);
  concurrency; OIDC вместо долгоживущих секретов; Scorecard как непрерывный аудит.
- **Репо-самоаудит**: OpenSSF Scorecard + OSPS Baseline (машиночитаемый
  каталог соответствия); Allstar и scorecard-monitor — паттерн «сверка состояния
  с политикой → issue при дивергенции»; GitHub durable-owner — CronJob-реконсиляция
  с закрытием расхождений; правила → rulesets; Security overview как дашборд.

Эмерджентное: во всей мировой канве **нет органа, который проверяет живость самих
аудиторов**. Scorecard мерит репо, Allstar мерит политики — но если планировщик
аудита замолчал, это заметит только человек. Закрыто ниже (§4).

## 3 · Эмерджентный синтез (только своё)

- **Принцип трёхслойного доказательства**: живой орган считается живым, только
  если (а) прогон зелёный, (б) факт запечатан в репо, (в) след свежий. Одного
  зелёного прогона недостаточно — это и есть дыра, через которую дом молчал 8 дней.
- **Дозор дозора**: отдельный минимальный орган (только репорт, лечение не
  выполняет — закон ревизора), который сверяет (1) печать дома (набор archived)
  с baseline — GitOps-реконсиляция печати; (2) живость органов-дозоров (canon
  workflow state=active); (3) свежесть снимков; (4) исторические следы реестра.
  Дивергенция → ALARM-issue с дедупом по WARDEN-FP; зелёный — молчит (анти-спам).
- **Seal-step**: коммит факта через API с ВИДИМЫМ отказом (exit 1) — против
  молчаливого `False` в логах. Мем: «если доказательство не запечатано в репо,
  его не существует».
- **Печать как первый-class состояние**: архивация дома — не хаос, а печатается
  в baseline; вскрытие печати без хозяина = ALARM (трипваер наоборот).
