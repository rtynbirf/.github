# Код-владелец по умолчанию на весь аккаунт (П36)

*Волна ×4 · 2026-11-11 · repo `.github` · предложение FIX-1.3 П36*

## Правило

**Каждое новое репо аккаунта наследует мембрану отсюда.** Файл
[`CODEOWNERS`](../CODEOWNERS) этого мета-репо — канон кода-владельца по
умолчанию: `* @rtynbirf`. Он держится автогеном, а не руками:

```bash
python3 tools/generate-codeowners.py --check .github/CODEOWNERS   # CI-гейт
python3 tools/generate-codeowners.py --print > .github/CODEOWNERS # перегенерация
python3 tools/generate-codeowners.py --audit                      # срез наследования
```

## Как это работает честно

- **org-аккаунт**: GitHub нативно берёт CODEOWNERS из `.github`-репо как
  org-wide default для всех репо без собственного файла.
- **user-аккаунт** (наш случай): нативного наследования у GitHub нет —
  дефолт держат три машины: (1) канон в автогене (`tools/generate-codeowners.py`),
  (2) CI-гейт `account-facade.yml` сверяет файл с каноном — расхождение красное,
  (3) `--audit` показывает, какие репо живут под дефолтом, а какие завели свой
  CODEOWNERS. Размножение канона в новые репо — доктрина + волна CI,
  а не надежда на платформу.
