# Сверка спецификации (Step 0)

Канонический протокол: `.github/docs/ПРОТОКОЛ-СВЕРКИ-СПЕЦ-КОД.md` (автор — агент-пилот
A0/hologram, коммит 201/c42b2e4). Навык не дублирует его — загружай и исполняй.

Короткий скелет:
1. Найди в репо спецификацию (конституция/устав/канон/стандарт).
2. Выпиши статьи → найди точки принуждения (код/CI/документы) → каждому пункту вердикт.
3. Вердикты только: **PASS** / **PARTIAL** (назвать, чего не хватает) / **FAIL** (назвать нарушение).
4. Результат: `docs/AUDIT-<репо>.md` + запись в ЛЕТОПИСЬ-ФАКТОВ (A-xxx) — запись только вперёд.

Референсы исполнений: khozyain I1–I7 (4 PASS + 3 PARTIAL), singulyar-a0-audit X-019…X-027.
Проверено: директива AGENTS.md требует Step 0 первым делом — не пропускать.
